¿Qué es Godot?

Godot Engine es un motor de videojuegos gratuito y de código abierto que permite crear videojuegos y aplicaciones 2D y 3D.

Un motor de videojuegos es un conjunto de herramientas que permite desarrollar un juego sin tener que programar desde cero sistemas como gráficos, física, sonido, animaciones, entrada del jugador, escenas, etc.

Godot está diseñado para trabajar desde una misma interfaz y permite desarrollar proyectos para Windows, Linux, macOS, Android, iOS y la web, además de permitir trabajar con consolas mediante soluciones de terceros.

En pocas palabras: Godot es un programa que reúne las herramientas necesarias para crear videojuegos.

  • 🎨 Prototipos

¿Qué herramientas incluye?

Godot intenta reunir en un solo programa buena parte de las herramientas necesarias para desarrollar un videojuego.

🎨 Gráficos 2D

Godot tiene un sistema específicamente orientado al desarrollo 2D. Incluye:

  • Sprites
  • Animaciones
  • TileMaps/TileSets
  • Partículas
  • Iluminación 2D
  • Sombras
  • Cámaras
  • Física 2D
  • Parallax
  • Sistemas de partículas
  • Dibujo personalizado

Esto hace que sea especialmente apropiado para juegos como plataformas, RPG 2D, juegos de pelea, juegos de ritmo, etc.

🧊 Gráficos 3D

También permite desarrollar juegos 3D con herramientas para:

  • Modelos 3D
  • Cámaras
  • Iluminación
  • Materiales
  • Sombras
  • Animaciones
  • Física
  • Colisiones
  • Navegación
  • Partículas
  • Entornos 3D

Sin embargo, una de las características de la filosofía de Godot es que algunas tareas avanzadas de creación de contenido 3D pueden requerir programas externos o complementos.

Por ejemplo, normalmente podrías utilizar Blender para crear modelos 3D y después importarlos a Godot.

El sistema de nodos

Una de las características más importantes de Godot es su sistema basado en nodos (Nodes).

Un nodo es un elemento que realiza una función determinada.

Por ejemplo:

Player
├── Sprite2D
├── CollisionShape2D
├── Camera2D
└── AudioStreamPlayer

Aquí Player puede ser el personaje y los nodos hijos pueden encargarse de:

  • mostrarlo
  • detectar colisiones
  • controlar la cámara
  • reproducir sonidos

Los nodos pueden combinarse para crear objetos más complejos.

¿Qué son las escenas?

Las escenas (Scenes) son otra parte fundamental de Godot.

Una escena puede contener un conjunto de nodos que forman un objeto o una parte del juego.

Por ejemplo:

  • Player.tscn
  • Enemy.tscn
  • MainMenu.tscn
  • Level1.tscn
  • Boss.tscn

Puedes crear un enemigo como una escena y después utilizarlo muchas veces dentro del juego.

Esto permite reutilizar fácilmente componentes.

¿Con qué lenguaje se programa?

Godot tiene varias opciones.

🟦 GDScript

Es el lenguaje creado específicamente para Godot. Su sintaxis es relativamente sencilla y está muy integrada con el motor. 

extends CharacterBody2D

var speed = 300

func _physics_process(delta):
    var direction = Input.get_vector("left", "right", "up", "down")
    velocity = direction * speed
    move_and_slide()

Godot recomienda GDScript especialmente para principiantes.

🟪 C#

También puedes utilizar C#, especialmente si ya tienes experiencia con este lenguaje. Sin embargo, necesitas utilizar la versión .NET de Godot para trabajar con C#.

🟧 C y C++

Mediante GDExtension puedes utilizar C y C++, entre otros lenguajes compatibles con esta tecnología. Esto puede ser útil cuando necesitas código de alto rendimiento.

Godot permite incluso combinar lenguajes: por ejemplo, utilizar GDScript para la lógica normal y C++ para una parte que necesite mucho rendimiento.

¿Es gratis?

Sí. Esta es una de las características más importantes de Godot.

Godot es software libre y de código abierto y utiliza la licencia MIT.

Esto significa que puedes:

  • Descargarlo gratuitamente
  • Utilizarlo comercialmente
  • Modificar el motor
  • Estudiar su código
  • Distribuir versiones modificadas
  • Crear juegos comerciales
  • Vender tus juegos

Además, Godot no cobra regalías por los juegos que hagas con él.

Eso sí: los proyectos creados con Godot deben cumplir los requisitos de la licencia MIT del motor, y los recursos de terceros que utilices —como música, fuentes, modelos o imágenes— pueden tener sus propias licencias.

Ventajas de Godot

✅ 1. Es gratuito

No necesitas comprar una licencia para utilizar el motor.

Esto lo hace muy accesible para:

  • estudiantes
  • principiantes
  • desarrolladores independientes
  • pequeños estudios

✅ 2. Es de código abierto

Puedes consultar el código fuente del motor.

Esto significa que la comunidad puede:

  • estudiar cómo funciona
  • detectar problemas
  • crear modificaciones
  • contribuir al proyecto
  • desarrollar herramientas adicionales

✅ 3. Excelente para juegos 2D

Godot cuenta con un sistema 2D dedicado y herramientas específicas para este tipo de juegos.

Esto lo hace muy atractivo para:

  • plataformas
  • RPG 2D
  • juegos pixel art
  • juegos de ritmo
  • shooters 2D
  • juegos de cartas
  • novelas visuales

✅ 4. También permite hacer juegos 3D

No está limitado a juegos 2D. Puedes desarrollar proyectos 3D completos utilizando sus herramientas de renderizado, física, animación, iluminación, cámaras, etc.

✅ 5. Es multiplataforma

Puedes desarrollar un proyecto y posteriormente exportarlo a diferentes plataformas.

  • 🪟 Windows ✅
  • 🐧 Linux ✅
  • 🍎 macOS ✅
  • 📱 Android ✅
  • 📱 iOS ✅
  • 🌐 Web ✅
  • 🎮 Consolas ⚠️ Principalmente mediante terceros

Godot busca que un mismo proyecto pueda adaptarse a diferentes plataformas.

✅ 6. GDScript es relativamente fácil de aprender

GDScript fue diseñado específicamente para Godot y para las necesidades del desarrollo de videojuegos. Su sintaxis es sencilla y tiene una integración muy estrecha con el editor.

✅ 7. Tiene un editor integrado

No necesitas construir todos los sistemas desde cero.

El editor permite trabajar con:

  • escenas
  • nodos
  • scripts
  • animaciones
  • físicas
  • recursos
  • audio
  • partículas
  • UI
  • depuración

✅ 8. Sistema de escenas muy flexible

Puedes convertir prácticamente cualquier componente del juego en una escena reutilizable.

Por ejemplo:

  • Player.tscn
  • Enemy.tscn
  • Bullet.tscn
  • Coin.tscn
  • Chest.tscn
  • Boss.tscn

Después puedes reutilizarlos en diferentes niveles.

✅ 9. Buena comunidad

Al ser código abierto, existe una comunidad que desarrolla:

  • tutoriales
  • plugins
  • addons
  • herramientas
  • ejemplos
  • documentación
  • proyectos

La propia documentación oficial ofrece tutoriales para aprender desde cero.

Desventajas de Godot

❌ 1. Menor presencia en algunos sectores profesionales

Aunque Godot ha crecido considerablemente, otros motores tienen una presencia histórica mayor en determinados estudios y proyectos comerciales.

Esto significa que dependiendo del trabajo que busques, puedes encontrar más ofertas que pidan experiencia con otros motores.

❌ 2. Menos herramientas 3D integradas que algunos competidores

Godot puede hacer juegos 3D, pero algunas herramientas avanzadas de creación de contenido 3D pueden requerir software externo o addons.

La propia documentación señala que el entorno 3D no tiene tantas herramientas integradas como el 2D para determinadas tareas.

Por eso es habitual combinar Godot con herramientas como Blender.

❌ 3. Consolas

El desarrollo para consolas puede ser más complicado que para PC o móvil.

Godot puede utilizarse para proyectos de consola, pero normalmente se requiere trabajar con proveedores o terceros especializados en ports, en lugar de tener un flujo oficial idéntico al de PC.

❌ 4. Menos recursos educativos que motores más populares

Existe mucha documentación y tutoriales de Godot, pero dependiendo del tema concreto puedes encontrar considerablemente más material sobre otros motores.

Esto puede ser especialmente evidente cuando buscas tutoriales muy específicos.

❌ 5. Cambios importantes entre versiones

Godot 3 y Godot 4 tienen diferencias importantes.

Por ejemplo:

  • Godot 3.x
  • Godot 4.x

Los proyectos y tutoriales de una versión no siempre son directamente compatibles con otra. Esto puede causar problemas cuando encuentras un tutorial antiguo.

❌ 6. Algunas características todavía tienen limitaciones

Por ejemplo, en la documentación actual, los proyectos de Godot 4 que utilizan C# no pueden exportarse a Web. También existen determinadas limitaciones en el soporte móvil de C#.

Por eso conviene elegir el lenguaje y la versión teniendo en cuenta la plataforma objetivo.

Godot vs. un programa de programación normal

Una diferencia importante es que Godot no es simplemente un editor de código.

Un programa como Visual Studio Code principalmente te proporciona herramientas para escribir código.

Godot, en cambio, integra:

  • Programación
  • Gráficos
  • Física
  • Audio
  • Animación
  • Interfaz
  • Escenas
  • Exportación
  • Depuración

Por eso se considera un motor de videojuegos.

¿Quién creó Godot?

Godot comenzó como un motor desarrollado internamente por un estudio argentino de videojuegos. Posteriormente pasó a convertirse en un proyecto de código abierto.

Actualmente su desarrollo es comunitario y está respaldado por la Godot Foundation, una organización sin fines de lucro.
